# Hi, I'm Isabella!!

**`Software Engineering Student`** · **`C/C++ & Systems`** · **`Backend Engineering`**

<br/>

I’m a Software Engineering student focused on developing strong foundations in **computer science, software engineering, and systems programming**.

I’m especially interested in understanding software beyond high-level abstractions — including **memory, data structures, algorithms, computer architecture, operating systems, performance, and low-level systems** — while also developing the skills required to design and maintain larger software systems.

My technical background includes **C/C++ for systems and performance-oriented programming** and **Java for software and backend engineering**, alongside Python and SQL.

Rather than focusing on a single language or framework, my goal is to become a versatile Software Engineer with strong fundamentals who can understand problems deeply, choose appropriate tools, and build reliable and well-designed systems.
